# 🏫 DIT NOW

> **동의과학대학교 학생을 위한 AI 스마트 캠퍼스 서비스**<br>
> "학교의 모든 정보를 내 손안에서, 더욱 간편하고 편리하게"

> **현재 구현 상태:** `mvp/`는 React/Vite/Tailwind의 브라우저 저장소 기반 시연 앱입니다. 아래 AI 비서·지도·학교 시스템 통합은 제품 목표와 제안 기능이며 구현 증거가 아닙니다. [DEC-015](docs/11_DECISION_LOG.md)에서 프런트 스택과 FastAPI 백엔드를 확정했지만 FastAPI 서버·공유 DB·실제 학교 연동은 아직 없습니다. 제출 자격의 별도 차단 사항은 [심사 규정 확인](docs/dev-prep/02_HACKATHON_ELIGIBILITY.md)을 참고하세요.

<br>

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | DIT NOW |
| 대상 | 동의과학대학교 재학생 (특히 신입생·편입생) |
| 개발 기간 | 2026.10.29 ~ 30 |
| 한 줄 소개 | 자연어로 묻고, 실시간 위치 기반으로 캠퍼스 시설까지 안내받는 AI 캠퍼스 앱 |

### 문제 정의
- 캠퍼스 건물·시설이 많아 **처음 오는 학생은 강의실·편의시설 위치를 찾기 어렵습니다.**
- 학교 정보가 여러 곳에 흩어져 있어 **필요한 정보를 빠르게 찾기 힘듭니다.**

### 해결 방법
- 학생이 **평소 말투 그대로 질문**하면 AI가 의도를 이해하고 답변합니다.
- 사용자의 **현재 위치를 기준으로 목적지까지 경로**를 안내합니다.
- 학교의 모든 시스템을 통합하여 학생, 교직원이 더욱 편리하게 학교생활을 할 수 있게 도와줍니다.

<br>

## ✨ 주요 기능

### 1. 🤖 캠퍼스 AI 비서
- 자연어 질문 이해 (예: "정보관 어디 있어?", "가장 가까운 편의점 알려줘")
- 교내 시설 데이터 기반 답변 (위치, 용도, 운영 정보 등)

### 2. 🧭 실시간 위치 기반 길찾기
- 현재 위치 → 목적지 경로 안내
- 지도 위 건물·시설 표시

### 3. 🏢 시설 정보 조회
- 건물별 시설 목록 및 상세 정보

### 4. 개인 시간표 조회
- 본인의 수강신청내용을 바탕으로 본인에게 맞춰진 시간표 조회
- 현재학점, 졸업학점등을 표시하여 더욱 계획적인 학교생활

## 🚀 실행 방법

### 1. 저장소 클론
```bash
git clone https://github.com/not-a-devs/ditNow
cd ditNow
```

### 2. 패키지 설치
```bash
cd mvp
npm ci
```

### 3. 현재 시연 앱 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`에 접속합니다. 시연 계정과 범위는 [MVP 안내](mvp/README.md)를 참고하세요. 현재 저장소에는 FastAPI 실행 명령·`requirements.txt`·DB 마이그레이션이 없습니다. 서버 구현 후 실제 설치·환경 변수·실행 방법을 추가합니다.
