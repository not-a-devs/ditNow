# DIT NOW AI 개발 태스크 생성 기준 v1.0 초안

이 문서는 태스크 분해 기준이며 개발 착수 지시가 아니다. [기존 AI 실행 규정](../10_AI_RUNBOOK.md)과 [기능 추적표](09_FEATURE_TRACEABILITY.csv)를 함께 사용한다. DEC-001~015는 변경하지 않는다. 신규 서버 태스크는 DEC-015의 FastAPI 경계를 사용하고 OPEN-002/003이 필요한 인증·DB 개설을 먼저 차단한다.

## 태스크 단위와 필수 입력
한 태스크는 한 사용자 여정의 검증 가능한 작은 단위다. TASK ID, FR ID, NFR ID, TC-V1 ID, 화면 경로, API 계약 ID, DB 테이블/관계, RBAC 정책 ID, 시드, 입력/출력, 상태 전이, 허용 파일, 완료 기준, 실행 명령, 정책 차단 조건을 적는다. 48개 기존 ID와 44개 신규 ID를 중복 구현하지 않는다. FR-ACA-002/FR-CAMP-001은 호환 상위 항목이며 세부 FR을 참조한다.

## 의존성 순서
1. 승인된 가상 신원/조직/학기/분반, 공통 오류·출처 계약과 기본 RBAC.
2. P0 핵심 익명 글·실명 모집·개인 기회 준비의 독립 CRUD와 교차 계정 차단.
3. 공지 원본/범위→outbox→학과·학년 채널 카드→알림/홈; 채팅 DB/실시간 복구.
4. AI 최소 원본 요약·실패 안전성; P0 검증과 README 첫 세 기능 일치 여부.
5. P1 강의실/자료/과제/질문·실명 지원·자유채널·화면 공유 PoC.
6. P2 입학·학사·출결·도서·생활관·지원·공개 정보의 업무별 설계/시연. 실제 운영은 미확정 정책별 차단을 해소한 후 별도 승인.

## 상태와 차단
READY: 모든 정책/입출력/권한/원장/AC가 확인된 시연 범위. BLOCKED_POLICY: 학교 권위 원장, 결제/환불, 공식 증명, 실제 성적·출결/합격, 민감 고충 등 승인 필요. BLOCKED_CONTRACT: 공통 API/DB/RBAC/시드 결정 전. DONE은 코드·DB·두 계정·오류·재조회·테스트 증거를 갖춘 경우에만. 문서 완료는 IMPLEMENTED가 아니다.

## 검증·리뷰
태스크 생성 전 추적표의 feature_id→API→RBAC→DB→NFR→TC를 확인한다. 구현 PR은 기존 결정 변경, 비공개 데이터 노출, 익명 신원, 권한 승격, 공지 중복, 가짜 공식 효력, 실제 학교 연동 문구를 차단 항목으로 리뷰한다. 테스트 미실행은 NOT_RUN으로 기록한다. 여러 사람이 같은 공통 스키마/권한 파일을 동시에 수정하지 않는다.

## 해커톤 우선순위
P0/P1/P2는 [기존 범위](../09_RELEASE_SCOPE.md)의 구현 단계 제안을 따라 배정했다. P0 후보가 많으므로 실제 구현 약속은 팀이 승인한 태스크에 한정한다. 첫 세 README CRUD 후보는 OPEN-001/DFLT-007의 미결정 상태다. P2의 학교 기본 기능이 제품 범위에서 빠졌다는 뜻이 아니다.
