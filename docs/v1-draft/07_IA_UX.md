## 핵심 흐름과 화면 상태
공지: 작성→대상 검증→게시 결과/배포 대기→대상 채널 참조 카드→원본/개정/첨부. 배포 실패 시 작성자에게 원본 게시 성공과 전달 실패를 별도로 표시한다. 학생은 채팅 카드에서 원본 권한을 다시 확인한다.

기회: 공식/외부 출처 확인→저장→준비 체크→외부 기관 직접 제출→본인 자기 기록. 자기 기록과 학교/기관 접수 확인을 다른 문구·배지로 표시한다. 공모전은 실명 모집으로 이동한다.

수업: 분반 선택→자료/과제/질문→교수 공유 시작→수강생 시청·자료 독립 확대→종료/재접속. 카메라·오디오·녹화는 기본 사용하지 않는다. 학습 진도·온라인 시험과 대면 출결은 분리 표시한다.

학사/입학/생활 신청: 작성중→검증→시연 접수번호→담당자 가상 심사→결과 확인. 공식 효력/결제/발급이 없는 화면은 항상 시연 표시를 한다. 신청이 중단되면 입력 보존·재시도·상태 조회를 제공한다.

## 공통 UX 계약
모든 화면은 loading, empty, success, validation-error, permission-denied, session-expired, conflict, network-error, unavailable 상태를 설계한다. 390px/1280px에서 핵심 동작이 잘리지 않아야 한다. 키보드 포커스/레이블/오류 안내/색 외 상태 표현을 갖춘다. 검색 결과는 접근 권한을 따르고 공식 공개 자료 A, 가상 운영 데이터 B, AI 요약을 구별한다. 고충·민감 상담은 검색 제안·알림 미리보기·홈 카드 본문에 노출하지 않는다.

## 화면 구현 차단
로그인 후 실제 학생정보/아레테/도서관 UI를 본 것처럼 복제하지 않는다. 원서/납부/증명 결과의 실제 효력 문구는 OPEN-R04/R06 전 차단한다. 현재 mvp 화면은 별도 브라우저 시연이며 위 경로·상태를 구현했다는 증거가 아니다.
