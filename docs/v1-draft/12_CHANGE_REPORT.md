# DIT NOW v0.2 대비 변경 보고서

작성일: 2026-10-29. 이번 변경은 docs/v1-draft/의 문서 11개와 CSV 1개만 추가한다. 기존 17개 명세 패키지, docs/research/의 11개 조사 문서와 별도 AI 환경 문서, NAV/AGENTS/CLAUDE, 애플리케이션 코드는 수정하지 않는다.

## 통합 결과
- 기존 FRD 카탈로그의 48개 FR ID를 그대로 유지했다.
- 조사 CSV에서 신규 44개 FR ID를 추가해 총 92개 고유 ID를 추적표에 넣었다. 누락 기본 기능은 입학 6, 학사 9, LMS/출결 5, 도서·취업·생활관·지원 14, 공개/학과 6, 운영/배지/편의 4 등 기존 한 줄 또는 미정의 영역을 업무별로 분해한 것이다. 세부 그룹은 [조사 보완](../research/05_FUNCTIONAL_REQUIREMENTS_GAPS.md)을 따른다.
- 기존 NFR ID와 14개 신규 보완 NFR ID를 연결했다. 신규 ID는 운영 기준 확정이 아닌 설계 제안이다.
- 역할별 범위, 데이터 원장, API 그룹, 화면, 테스트를 기능 ID별 CSV에서 연결했다.
- 존재 수준은 VERIFIED 40, PARTIAL 17, INFERRED 26, UNKNOWN 9다. 처리 규칙은 PARTIAL 36, UNKNOWN 56이며 VERIFIED 0이다. 이는 학교 홈페이지의 전체 기능 수가 아니라 조사 카탈로그 행 수다.

## 보존한 사용자 결정
DEC-001~014의 독립 통합 플랫폼, 기본 학교 기능 장기 범위, 학과 전체/학년 채팅과 자유·공식 채널, 대상별 공식 공지 자동 배포, 익명 자유/실명 모집, 기회와 외부 양식 직접 제출, 강의실·수업 채팅·교수 질문·PC 화면 공유, 문서화 선행을 유지했다. 기존 P0/P1/P2와 DFLT/OPEN 상태도 승인 없이 변경하지 않았다.

## 정리한 충돌
- FR-ACA-002와 FR-CAMP-001의 복합 업무는 원 ID를 호환 상위 항목으로 남기고 신규 세부 ID와 연결했다.
- FR-ATT-001의 시연 코드/QR 옵션과 학교 캠퍼스락 공지의 블루투스/인증번호를 같은 현행 구현으로 주장하지 않는다. LMS 온라인 출석과 대면 출결도 별도 원장이다.
- 공개 URL/메뉴의 기능 존재와 로그인 뒤 처리 규칙을 분리했다. 공지 CRUD·수정 이력 등 기존 복합 ID 7개는 PARTIAL이다.
- 루트 README의 AI 길찾기 중심 설명/기술 스택과 PRD의 통합 캠퍼스 비전은 여전히 충돌한다. README는 이 PR에서 수정하지 않았으며 별도 승인된 포지셔닝 결정이 필요하다.
- 현재 mvp localStorage 시연을 서버 DB·RLS·공식 학교 연동 구현으로 승격하지 않는다.

## 미해결
OPEN-001~009, OPEN-R01~R16과 실제 보존/SLA/원장/계약이 남아 있다. 입학·성적·출결·결제·증명·고충의 실제 운영은 차단된다. 학교 사이트의 로그인 전용 화면 및 모든 학과 게시물은 조사하지 못했다. 공식 자료의 재배포·갱신 권한도 미확정이다.

문서 자동 검사에는 고유 ID/기존 ID 보존/44개 신규 수/각 행의 AC·DB·RBAC·API·NFR·TC·근거·우선순위/내부 링크/상태 분리를 포함한다. 애플리케이션 빌드·DB·브라우저·배포 테스트는 수행 대상이 아니다. 실제 결과는 PR 검증 기록에 별도로 남긴다.
