# DIT NOW 통합 FRD v1.0 초안

기준: [기존 FRD](../02_FRD.md)의 48개 ID와 [조사 기능 목록](../research/04_FULL_FEATURE_CATALOG.csv)의 신규 44개 ID, 총 92개. 본 문서와 [기능별 추적표](09_FEATURE_TRACEABILITY.csv)는 함께 읽는 규범 계약이다. 추적표의 각 행에는 기능 설명·목적·학교 확인 동작·플랫폼 동작·역할·입출력·흐름·CRUD·상태·예외·DB·API·NFR·테스트·근거·우선순위가 있다. 학교의 존재 수준과 처리 규칙 수준은 별개다.

## 공통 완료 계약
모든 구현 대상 기능은 (1) 인증/범위 권한, (2) 서버 입력 검증, (3) 저장 또는 조회 원장, (4) 새로고침·재로그인 후 일관성, (5) 타 계정 거부, (6) 로딩·빈·검증·권한·네트워크 오류, (7) 추적표의 TC-V1 테스트를 통과해야 완료된다. 조회 전용 공개 콘텐츠는 3의 저장 원장 대신 출처 URL·확인일·개정 표시를 가진 스냅샷으로 충족한다. P2 또는 정책 차단 기능은 문서화 완료와 구현 완료를 혼동하지 않는다.

## 신원·조직·홈
FR-AUTH-001~003은 시연 전용 계정의 로그인·세션·승인된 역할/학과/학년/분반·실명 활동 프로필을 다룬다. 지원자에서 학생으로 전환은 관리자 승인 이벤트 없이는 일어나지 않는다. FR-HOME-001~003은 수업·공지·마감·개인 신청 상태를 원본 ID로 모으고 검색/알림을 권한 범위로 필터한다. 검색 결과의 공식/가상/AI 출처를 구별한다. FR-ADM-001~004는 역할 부여·콘텐츠 감사·신규 업무 역할·자료 출처를 관리한다.

## 공지·학과·협업
FR-NOT-001~005는 원본 공지의 draft→published→archived와 revision, 대상 범위, 중복 없는 outbox·전달 카드·읽음 정책을 다룬다. 공지 전체/학과/학년/분반/개인 대상은 서버가 승인된 작성 범위와 교차 검증한다. 전체 공지는 개인 알림/공식 목록으로 간다. 학과/학년/분반은 해당 기본 채널로 간다. 전송 실패는 원본 발행과 분리해 재시도하고 카드 중복을 금지한다.
FR-DEPT-001~008은 학과 전체/학년별 기본 채널, 학생 자유채널, 승인된 공식 채널, 채팅, 학과 게시판, 학과 소개/교육과정/뉴스를 같은 조직 키로 잇는다. 학과 콘텐츠는 출처·작성자·공식성에 따라 공지와 구별한다. 소속 변경 직후 이전 채널의 API·구독·파일 접근을 차단한다.
FR-COM-001~007은 익명 자유 글/댓글/신고와 별도 실명 모집·지원·팀 공간이다. 익명 공개 API에는 작성자 UID·실명·소속 결합값이 없어야 한다. 실명 모집은 정원·마감·승인 동시성을 DB에서 보장하고 공모전 공고와 원본 ID로 연결한다.

## 기회·수업
FR-OPP-001~006은 장학금·근로·공모전·취업/행사 공고, 개인 저장/체크, 외부 지정 양식·직접 제출, 교내 프로그램 신청을 다룬다. 공고별 submission_mode를 저장한다. 외부 접수 확인을 가장하는 상태는 허용하지 않는다. FR-JOB-001~004의 공개 채용 공고는 기회 원본을 재사용하되 이력서·상담 동의·기업 의뢰는 별도 보호 원장이다.
FR-COURSE-001~007과 FR-LMS-001~003은 학기별 분반·수강 명단·자료·과제·질문·채팅·교수 화면 공유·온라인 콘텐츠/시험을 같은 offering_id에 연결한다. 교수만 화면 공유를 시작하고 등록 수강생만 시청한다. 원본 PPT/PDF는 독립 확대 가능하다. 오디오·녹화 기본 OFF. 온라인 학습 출석과 대면 출결의 공식 합산 규칙은 미확인이다.

## 학사·입학·생활
FR-ACA-001~011은 일정/시간표, 개설강좌/수강, 성적·졸업, 휴복학/재입학/전과, 성적포기, 증명, 등록금으로 분해한다. FR-ACA-002는 기존 호환 상위 ID이며 상세 업무는 003~011을 따른다. 신청→접수→검토→승인/반려→반영 상태를 분리하고 공식 규정 수치를 시연 상수로 만들지 않는다. FR-ATT-001~004의 대면 체크·정정·모바일학생증은 자체 시연 출결과 공식 캠퍼스락 사실을 구분한다.
FR-ADMIS-001~006은 모집요강·지원·서류/면접·합격/납부 조회·등록포기/환불·상담을 지원자 전용 경계에 둔다. 실제 금융 처리와 공식 합격 판정은 차단한다. FR-CAMP-001은 기존 상위 ID이며 지도/편의시설/예약은 FR-CAMP-002~003 및 FR-LIB-001~004의 세부 계약을 따른다. 도서 거래와 공간 예약은 가상 재고·슬롯 원장과 경합 검사로만 시연한다.
FR-DORM-001~002는 생활관 안내와 가상 신청/배정, FR-HELP-001~004는 민원·고충·장애학생지원·봉사를 다룬다. 고충의 온라인 본문 접수는 별도 개인정보 운영 승인 전 차단하고 공개 안내만 제공한다. FR-CRED-001은 가상 배지와 공식 배지 발급 주체를 혼동하지 않는다. FR-WEB-001~004는 대학 소개·캠퍼스·정보공개·홍보 원본을 출처/개정과 함께 제공한다.

## 구현 차단 조건
추적표의 implementation_gate가 UMBRELLA인 두 기존 ID는 중복 구현하지 않는다. BLOCKED인 민감 고충 본문, 실제 입학 결과·납부·환불, 공식 증명은 운영자/정책·계약 승인 전 시연 상태만 문서화한다. PARTIAL/UNKNOWN의 처리 규칙을 학교 규정으로 승격하지 않는다. 모든 정책 질문은 [미확정 목록](11_OPEN_POLICIES_ASSUMPTIONS.md)에 남긴다.
