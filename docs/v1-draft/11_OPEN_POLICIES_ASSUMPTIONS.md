## 시연 기본 원칙
A는 공개 공식 자료의 원본 URL·확인일·출처, B는 가상 계정/수업/성적/출결/채팅/신청 기록이다. 계정·학적은 가상이다. 출결·성적은 자체 시연 원장에만 저장한다. 실제 결제·납부·환불, 공식 증명 발급, 학교 SSO·운영 DB 연동은 수행하지 않는다. 상담·고충은 엄격히 분리하고 고충 본문 온라인 접수는 승인 전 차단한다. 시연 데이터는 실제 학생 정보처럼 보이지 않도록 UI/API/내보내기에 표시한다.

## 사실과 가정의 표기
VERIFIED는 공개 페이지에서 해당 존재/행동이 확인된 범위에 한한다. PARTIAL은 일부만 확인, INFERRED는 설계 후보, UNKNOWN은 근거 부족이다. existence_level과 rule_level은 각각 따로 기록한다. 공개 페이지의 메뉴가 로그인 뒤 CRUD·승인·보존 규칙의 증거는 아니다. [92행 근거](09_FEATURE_TRACEABILITY.csv)에 source_url/checked_date와 두 수준이 있다.

## 우선 해결할 질문
신원·소속 승인 책임자, 학생정보/LMS/캠퍼스락 중 권위 원장, 학사 규정 버전, 입학·금융 권한, 고충 비밀 처리, 공식 증명 효력이 가장 시급하다. 이 결정을 못 해도 공개 정보와 가상 시연의 독립 태스크는 진행 가능하다. 실제 운영으로 전환하는 태스크만 BLOCKED_POLICY다.
