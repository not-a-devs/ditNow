# DIT NOW 통합 PRD v1.0 초안

상태: 설계 초안, 2026-10-29. 기존 사용자 확정 방향은 [결정 대장](../11_DECISION_LOG.md)의 DEC-001~014를 그대로 따른다. 학교 현행 기능에 관한 근거와 불확실성은 [조사 CSV](../research/04_FULL_FEATURE_CATALOG.csv)와 [기능 추적표](09_FEATURE_TRACEABILITY.csv)를 따른다. 이 문서는 실제 학교 시스템 운영 승인이나 구현 완료를 의미하지 않는다.

## 제품 정의와 범위
동의과학대학교의 공개 서비스와 교내 업무 흐름에서 확인된 주요 기능을 자체 계정·권한·데이터로 재구현하고, 공지·학과 소통·수업·기회·협업·개인 액션을 한 흐름으로 잇는 웹 플랫폼이다. 장기 제품 범위와 해커톤 P0/P1/P2는 분리한다. 기존 [릴리스 범위](../09_RELEASE_SCOPE.md)의 P0 핵심 3 CRUD 후보, 공지 자동 배포, 학과 채팅, AI 브리핑을 임의로 승격하거나 변경하지 않는다.

## 대상 사용자
공개 방문자, 입학 지원자, 학생, 졸업생, 교수, 조교, 학과 담당자, 학년 대표, 학교 담당자, 입학 담당자, 사서, 취업 담당자, 생활관 담당자, 상담자, 민감 고충 담당자, 기업 담당자, 관리자. 사용자 신원 및 범위는 시연 DB에서 승인된 역할 할당으로만 정한다. 지원자는 학생이 아니며 졸업생의 강의/학과 권한은 별도 승인 없이는 없다.

## 사용자에게 제공할 핵심 여정
1. 공식 공지: 권한자가 원본을 게시하면 대상 학과·학년·분반 채널에 참조 카드가 한 번 생성되고 개인 알림과 홈으로 이어진다. 수정은 같은 원본의 개정으로 표시한다.
2. 기회 발견: 학교/외부 공고의 원문·출처·기한을 보고 개인 체크리스트를 만든다. 외부 기관 제출 여부는 학생 자기 기록이며 기관 접수 사실이 아니다. 공모전 공고에서 실명 팀 모집으로 이어진다.
3. 학과·수업: 소속으로 학과 전체/학년 채널을 이용하고 학생 자유채널을 만든다. 강의실은 수강 명단과 연결되어 자료·과제·공지·질문·수업 채팅·화면 공유를 제공한다.
4. 익명과 실명: 익명 자유게시판의 공개 응답과 실명 프로젝트 프로필은 분리한다. 운영상 신고 처리는 제한된 감사 경로를 통한다.
5. 학사·생활: 공개 학사 일정·입학·도서·취업·생활관·지원 정보를 한 검색/탐색 체계에서 찾되, 개인 거래/성적/증명/납부는 자체 시연 원장에만 기록한다.

## 제품 원칙
- 공통 계정, 조직·분반·범위 권한, 원본 데이터, 알림, 검색과 UX를 사용한다.
- 공식 공개 자료 A와 가상 시연 운영 데이터 B를 UI·API·출처 기록에서 구별한다. 실제 학생·교직원 계정/학번/성적/출결은 수집하지 않는다.
- 실제 학교 SSO, 학생정보시스템, 아레테, 캠퍼스락, 도서관 운영 DB에 연결된 것처럼 표시하지 않는다.
- 실제 결제·환불·공식 증명 발급은 수행하지 않는다. 민감 상담·고충은 일반 검색·AI·알림 미리보기에서 제외한다.
- AI는 원장 결과를 만들지 않고, 권한 확인된 원본을 요약하고 출처로 이동시킨다.

## 성공·출시 판단
P0의 해커톤 판정은 [기존 QA](../08_TEST_QA.md)와 [통합 QA](08_TEST_QA.md)의 실제 계정·서버 DB·교차 권한·새로고침·오류 증거에 따른다. 문서에 기능을 적었다는 사실만으로 구현 완료가 아니다. 장기 제품의 실제 학교 운영은 OPEN-R01~R16의 업무 주체·신원·원장·규정·재배포·보존 승인이 필요하다. 효과 수치는 실측 전 가설로 표기한다.

## 요구 범위와 제외
장기 범위는 92개 고유 FR ID 전체다. [추적표](09_FEATURE_TRACEABILITY.csv)의 P0/P1/P2는 구현 순서 제안이며 사용자 승인 범위를 바꾸지 않는다. 공개 웹의 모든 게시물·학과별 모든 메뉴, 로그인 뒤 교내 거래 규칙은 검증되지 않았다. 상품/결제/발급 공급자 계정, 실제 지원 결과, 공식 학사 확정 권한은 본 시연 범위 밖이다.
