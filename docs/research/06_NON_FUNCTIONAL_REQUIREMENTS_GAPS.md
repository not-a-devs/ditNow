# NFR 보완안

기존 [NFR](../03_NFR.md)의 인증·RLS·익명성·중복 방지·접근성 요구는 유지한다. 아래 신규 ID와 수치는 **v1.0 설계 제안**이며 학교 운영 기준이나 법적 준수 완료 주장이 아니다. 측정값/보존기간/복구 목표는 운영 주체 결정 후 확정한다.

| 신규 ID | 보완 요구 | 검증 증거 / 합격 기준(제안) |
|---|---|---|
| `NFR-ID-001` | 지원자·학생·졸업생·교직원 계정의 신원 원장/전환을 분리한다. | 임의 지원자가 학생 권한을 획득할 수 없고 입학 확정 전 학생 데이터 없음. |
| `NFR-ID-002` | 학적·학과·학년·분반 변경 시 채팅/파일/실시간 구독 권한을 재평가한다. | 전과/휴학 반영 직후 이전 범위의 조회·실시간 이벤트·서명 URL 모두 거부. |
| `NFR-PRIV-004` | 입학·성적·상담·고충·이력서·도서대출 등 데이터 유형별 최소 접근과 별도 보존 정책. | 역할별 목록/상세/검색/로그/백업 접근 표와 타 계정 부정 테스트. |
| `NFR-PRIV-005` | 공개 공지/게시물/학과 콘텐츠에 출처·확인일·시연 여부·개정 이력을 표시한다. | 실제 공고와 가상 운영 기록이 UI/API/내보내기에서 구분됨. |
| `NFR-SEC-008` | 학사·입학·증명·환불·권한 승격 등 고위험 변경은 승인자와 행위자를 감사 가능하게 기록. | 요청/승인/반려/취소에 누가·언제·무엇을 남기며 일반 사용자에게 민감 메타가 보이지 않음. |
| `NFR-SEC-009` | 민원과 고충은 일반 게시판 인덱스·AI 입력·알림 미리보기에서 격리. | 검색/푸시/관리자 기본 목록에 제목·본문 노출 없음. |
| `NFR-REL-006` | 수강 정원, 공간 예약, 대출본, 생활관 배정의 동시성은 DB 원자성으로 보장. | 병렬 요청에서 정원/재고/슬롯을 초과하지 않음. |
| `NFR-REL-007` | 학사·입학·납부/증명 상태는 요청 접수와 최종 확정을 분리하고 재시도 멱등화. | 네트워크 재시도·중복 클릭 때 동일 신청/결제 상태 1건; 최종 상태는 권한 있는 원장만 변경. |
| `NFR-REL-008` | 업로드·외부 링크·제3자 서비스 장애의 부분 실패를 표시. | 첨부 실패 시 성공 오표시 없음; 외부 발급/신청 장애 시 상태 불명확 처리. |
| `NFR-OPS-005` | 공식 데이터 갱신 책임자·주기·원본 링크·스냅샷 시각을 관리. | 학사일정/공고 변경 시 이전 버전과 새 버전의 출처·검토자 추적. |
| `NFR-OPS-006` | 백업/복구 목표, 사고 대응, 데이터 보존·삭제, 운영자 접근 재인증을 정한다. | 복구 리허설·권한 회수·보존 만료 증거; 목표 수치는 운영 결정 전 `TBD`. |
| `NFR-UX-006` | 입학 지원·수강신청·출결·증명 신청의 단계와 공식 효력을 명확히 표시. | `작성중/접수/심사/확정` 혼동 없이 확인 화면·오류 복구 가능. |
| `NFR-UX-007` | 키보드·스크린리더·색상 외 표시·문서 대체텍스트 및 장애학생 지원 경로를 검증. | 핵심 신청/조회/오류 흐름에 WCAG 2.2 AA 기준 점검 결과 기록(목표). |
| `NFR-AI-005` | AI는 입학 결과·성적·출결·장학 자격·상담/고충을 원장 대신 판정하지 않는다. | 근거 없는 결과 출력 차단, 출처 링크/시연 표시, 비공개 자료 기본 미전송. |

### 수치와 규정의 출처 구분

기존 `NFR-PERF-001`의 모바일 Lighthouse 90점은 해커톤 목표다. 장기 대학 업무 서비스의 가용성/SLO/동시접속/복구시간으로 전용하지 않는다. [수강신청 안내](https://www.dit.ac.kr/kr/index.php?pCode=classreginfo)의 학점 범위, [증명 안내](https://www.dit.ac.kr/kr/index.php?pCode=certificate)의 수수료, [학사일정](https://www.dit.ac.kr/kr/index.php?pCode=univschedule)의 일정은 출처 시점이 있는 운영 데이터로 저장한다. 학교 측 현행 규정·계약 확인 전 영구 상수로 만들지 않는다.
