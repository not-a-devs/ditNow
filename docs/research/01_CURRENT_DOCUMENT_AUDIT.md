## 보존해야 할 사용자 결정

`DEC-001~014` 전체 보존. 핵심은 독립형 재구현, 주요 기본 기능의 **장기 설계 범위**, 익명 자유공간과 실명 협업 분리, 학과 전체·학년 채팅 및 학생 자유채널/공식채널 승인, 교수·조교 공지 자동 배포, 내 강의실 분리, 자료·과제·출결, 교수 PC 공유와 수업 질문, 외부 장학금 직접 제출, 문서 선행이다. [결정 대장](../11_DECISION_LOG.md), [PRD](../01_PRD.md).

## 승인되지 않은 제안 및 충돌

- `DFLT-001~008`은 기술/운영 기본값이지 확정이 아니다. 특히 Supabase/Vercel/LiveKit, outbox 구현 방식, 학교 전체 공지의 채팅 제외, 외부 지원 자기기록, README 3 CRUD 선정은 승인 상태를 유지한다.
- `OPEN-001~009`도 미결정이다. 공식 사이트 조사로 존재 확인이 되더라도 사용자 승인으로 자동 전환되지 않는다.
- PRD의 “기존 주요 기능 자체 재구현”과 “기존 학교 SSO·학적·성적·출결 실제 연동 안 함”은 **장기 제품/현재 시연 범위**를 분리하면 양립한다. 실제 운영 데이터·권한 없이 학교 업무를 처리했다고 주장할 수 없다.
- `FR-ATT-001`의 코드/QR 옵션은 [캠퍼스락 도입 공지](https://www.dit.ac.kr/kr/?idx=16153&mode=view&pCode=notice&pg=11)의 블루투스/인증번호 현행 경로와 다르다. 시연 옵션과 실제 학교 동작을 분리할 것.
- `FR-CAMP-001`의 “시설 예약”은 도서관 [그룹스터디룸/시네마존 예약](https://library.dit.ac.kr/Cheetah/DITL/Index/)은 확인되나 캠퍼스 전체 시설 예약은 확인되지 않았다.
- `FR-ACA-002`는 수강신청·성적·학적·증명 발급을 하나로 묶어 오류, 소유권, 승인, 원장 정합성, 결제 경계를 표현할 수 없다.
- `FR-OPP-003`의 외부 직접 제출은 사용자 경험으로 확정된 **해당 유형** 흐름이다. 모든 장학 공고에 동일 규칙을 적용하면 [장학 게시판](https://www.dit.ac.kr/kr/index.php?pCode=scholarship)의 교내/교외/국가근로 유형 차이를 잃는다.
- 학과 목록은 [학교 첫 화면](https://www.dit.ac.kr/kr/)과 [대학 페이지 메뉴](https://www.dit.ac.kr/kr/index.php?pCode=compusvr)의 표시가 일부 다르다. 현재 유효 학과·코드·폐지/개편 이력을 별도 원장으로 확정해야 한다.
- 저장소 [루트 README](../../README.md)는 “DIT NOW”의 AI 캠퍼스 비서·실시간 위치 길찾기와 FastAPI/Kakao 지도 중심을 전면에 놓지만 [PRD](../01_PRD.md)와 [결정 대장](../11_DECISION_LOG.md)은 학사·수업·소통·기회를 통합하는 “DIT Campus(가칭)”를 확정 방향으로 둔다. 명칭·우선 기능·기술 스택이 충돌한다. README를 근거로 DEC-001~014를 바꾸지 말고 제품 포지셔닝 결정을 별도로 기록해야 한다.
- [사전 MVP 안내](../../mvp/README.md)는 서버 DB 없는 프런트 프로토타입임을 명시한다. [저장소 코드](../../mvp/src/shared/data/store.ts)는 `localStorage`와 탭 간 `BroadcastChannel`, [모의 API](../../mvp/src/shared/data/api/core.ts)는 `sessionStorage` 신원을 쓴다. 따라서 현행 코드의 CRUD/권한/실시간을 서버 DB·학교 인증·다기기 실시간 구현 완료로 기록할 수 없다.

## 구현 전 질문 발생 가능성이 큰 영역

학사/수강/성적 규정의 연도별 적용, 실제 계정 검증·신원 원장, 입학 지원자의 개인정보와 합격/납부 상태, 출결·LMS 간 동일 수업 매핑, 도서관 대출·예약 자격/벌칙, 공지 원본의 학교/학과별 편집권, 상담의 비밀 범위, 증명서 발급·결제 주체, 운영 데이터 출처·재사용 권한. 상세 결정은 [09](09_UNVERIFIED_AND_OPEN_QUESTIONS.md)에 정리한다.
