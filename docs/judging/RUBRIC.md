코드 합계 50점. 구동의 정적 예시 자료는 DB CRUD 점수 근거가 아니며 일부만 동작할 때의 부분점수와 전체 성공을 구별한다. N+1·운영 지연은 코드/측정 증거에 따라 판단하며 추정으로 현재 HTTP 실패 원인이라고 단정하지 않는다.

## 상한과 근거 부재

1. 근거를 제시하지 못한 세부 칸은 0이다. 파일·줄, 실제 사용 기록·사진, 측정값의 실행 SHA와 환경을 함께 제시한다.
2. 서비스 접속이 불가능하면 구동은 코드 근거로 최대 4다.
3. 구동이 5 미만이면 로그인·보안 및 안정성·확장성은 각각 최대 5다.
4. 평문 비밀번호, 브라우저 비밀 유출, 무인증/타 계정 자료 접근 같은 치명 결함이 확인되면 보안 최대 3이다. 재실행 실패만으로 치명 결함이 있다고 단정하지 않는다.
5. 로그인 기능 부재이면 관련 로그인·보호·소유권 세부 칸은 0, AI 기능 부재이면 AI 전체 0이다.
6. 규칙 추천·검색·Pydantic 계약·개발용 Claude 호출을 서비스의 실제 AI 제공으로 인정하지 않는다. Lighthouse 3회 미실행의 측정점은 0이다.
7. 로컬 단위·CI 성공은 공개 서비스 접속·DB E2E·대면 발표 성공을 대신하지 않는다.
