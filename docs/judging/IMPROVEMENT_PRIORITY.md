## 점수와 직접 연결되는 제한

- 공개 접속이 입증되지 않으면 구동 상한4 및 보안/안정성 상한5의 위험이 가장 크다.
- 메모리 전용 지원/프로필/액션/채널/운영 제안 모듈은 공유 DB 동시사용4점의 근거가 아니다. 기능 수를 늘려 이 점수를 회복하지 않는다.
- 개인 준비 목록은 [서비스](../../services/api/app/features/opportunities/service.py)225행과 [SQL 저장소](../../services/api/app/repositories/opportunities_sql.py)194행부터 전량 조회한다. 서비스의 행별 상세 투영도 검토 대상이다. 전체 시스템의 N+1 제거 완료라고 표시하지 않는다.
- 실제 LLM을 호출하지 않았으므로 AI5점 확보를 주장하지 않는다. 개발용 Claude 작성량도 제품 AI 가점과 무관하다.

## 병렬 소유권

root는 공통 App/API/설정·원격DB/실제 실행·NAV/진행표를 관리한다. 독립 작성자는 각 기능의 허용 파일만 소유하며 Codex는 Claude 작성 코드의 소스·테스트를 검토한다. 이번 심사 작업자는 docs/judging의6파일만 수정한다. 운영 비밀·DB·서버·실제 장치·실제 LLM에는 접근하지 않는다.
