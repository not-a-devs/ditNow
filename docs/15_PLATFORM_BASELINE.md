# 대학 통합 플랫폼 전체 기본 기능 목록 (누락 방지용)

> **제품 기준 기능 목록**. 여기의 기능은 동의과학대학교 현재 시스템에 실제 존재함을 주장하지 않는다. 실제 기능 채택 여부는 `13_EXISTING_SERVICE_AUDIT.md` 전수조사와 운영정책으로 검증한다. 별도 상세 FRD 미작성 항목은 구현 전 동작/권한/수용 조건을 추가해야 한다.

## A. 공통·계정·인증
- 계정 가입/초대/로그인/로그아웃/비밀번호 초기화/세션 만료
- 학생/교수/조교/총대/직원/관리자 다중 역할과 범위 기반 권한
- 소속 학과/학년, 학기, 강의 수강 정보와 프로필 관리
- 개인 알림함, 수신 설정, 읽음/미확인, 통합 검색, 접근성·다국어 확장 여지
- 공식 정보와 커뮤니티 정보/AI 정보를 구분하는 신뢰 표시

## B. 학사·학적
- 학사 일정/공지/학기/전공·교양 커리큘럼/교육과정 안내
- 강좌 개설/수강신청/수강정정/대기/시간표/분반/강의실
- 성적 조회·성적 정정 요청, 학점·졸업요건 조회
- 등록금·장학 안내, 휴학/복학/재입학/전과/졸업 등 학적 업무 및 신청
- 증명서 발급·서류 신청·상태 조회(실제 발급/수납은 공식 권한·연동 필요)
- 강의평가 및 학생 피드백(익명/개인정보 정책 별도)

## C. LMS·강의실·출결
- 수강 과목 홈/강의 공지/주차별 강의 자료/자료 다운로드·열람
- 과제 게시·제출·재제출·교수 피드백·점수/평가(학교 정책 필요)
- 출결 세션/코드·QR 체크·교수 최종 확인·정정 요청/이력
- 질문 게시판/교수 답변/실시간 채팅/수강생 명단·역할
- 대면 수업 PC 화면 공유/수강생 개별 시청·자료 확대
- 온라인 학습/퀴즈/토론/학습 진행률/시험(장기 범위)

## D. 학교·학과 정보 및 기회
- 학교 전체/학과/학년/수업별 공식 공지/첨부/검색/개정/조회
- 공식 공지 대상별 자동 채팅 참조 카드/개인 알림/중복 방지
- 장학금·교내근로·취업/자격증·공모전·대회·행사 모집
- 외부 지원 지정 양식·제출기관/방법 안내, 개인 준비 체크리스트·마감
- 학교 직접 운영 사업 신청/접수/승인/반려/상태 조회(공고 유형별)
- 상담/학생 지원/민원/FAQ/요청/답변·처리 단계 추적

## E. 커뮤니티·학과 소통
- 학교 전체 익명 자유게시판/학과 익명게시판/댓글/검색/좋아요
- 학과 전체/학년별/목적별 자유 채팅/수업 채팅/질문 채널
- 실명 모집: 공모전·프로젝트·스터디·동아리/팀원 역할/지원/승인
- 프로젝트 팀 대화/프로필·관심 분야/활동 이력·포트폴리오
- 신고/차단/스팸/제재/운영 정책/공식 배지 승인

## F. 캠퍼스 생활
- 건물·강의실 안내/지도/이동시간 계산/장애물 없는 동선 정보
- 도서관 도서/대출·반납·연장/열람실/좌석(운영 데이터 필요)
- 실습실·학습실·공간·장비 예약/이용 상태/사고 신고
- 학식·식당 메뉴, 교통·셔틀·주차(있다면), 편의시설
- 교내 학생회·동아리·행사/예약/참가 신청
- 학생증·결제·출입과 같은 민감/외부 권한 기능은 별도 검증 전 제품 비목표 후보

- 강의 개설·수강생 배정/자료/과제/출결/성적/피드백 관리
- 학과·학년·전체 공지 등록/승인/수정/자동 배포/확인 현황
- 장학금·근로·교내 사업 모집 등록/신청서 검토/결과 처리
- 학생 문의/민원/상담 및 운영 업무·처리 상태
- 조직·계정·역할·공식 채널·콘텐츠·신고·감사 기록 관리
- 이용 통계/콘텐츠 가시성/알림 발송 상태/오류 모니터링

## H. 차별화 기능과 기존 기본 기능 사이의 데이터 연결
| 데이터 이벤트 | 출처 | 학생에게 전달되는 곳 | 다음 행동 |
|---|---|---|---|
| 학과 공지 게시 | 조교/교수 | 학과·학년 채팅 공식 카드+공지함 | 원문 확인/저장/마감 등록 |
| 강의 공지 게시 | 담당 교수 | 내 강의실+학생 알림 | 자료/과제 확인 |
| 과제 마감 설정 | 강의실 | 홈 액션 센터/시간표 | 제출 준비 |
| 장학금 공고 등록 | 담당자 | 기회 피드+개인 관련 공고 | 파일 다운로드/준비 체크 |
| 공모전 공고 등록 | 기회 센터 | 실명 모집 연결 | 팀원 구하기/참가 신청 |
| 새 팀 지원 | 커뮤니티 | 팀장 알림/실명 모집 상세 | 승인/반려 |
| 실시간 수업 시작 | 강의실 | 해당 수강생 라이브 표시 | 화면 시청/질문 |
