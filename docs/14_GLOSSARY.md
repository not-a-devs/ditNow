# 용어 사전
| 용어 | 정의 | 구별해야 할 것 |
|---|---|---|
| 학과 허브 | 소속 학과별 공지/채팅/게시판의 통합 진입점 | 전교 커뮤니티와 구분 |
| 기본 채널 | 학과 전체 및 학과×학년 기준 시스템 관리 채널 | 학생 임의 삭제 불가 |
| 자유 채널 | 학생이 학과 내부의 목적별 수업 외 소통을 위해 생성한 채널 | 공식 배지 미부여 |
| 공식 채널 | 승인 권한자의 공식 표시가 붙는 공지/소통 공간 | 개인/학생 자유 채널과 구분 |
| 공식 공지 | 승인된 담당자가 작성/게시해 원본 `notice`로 저장된 정보 | 개인 채팅 메시지와 구분 |
| 전달 카드 | 공식 공지의 참조 ID와 최신 버전 링크를 가리키는 채팅 카드 | 공지 원문 복사본 아님 |
| 강의실 | 학기별 과목 분반(course offering)에 대한 학생/교수 전용 학습 공간 | 물리적 건물·호실과 구분 |
| 강의 자료 | 교수 등이 승인된 강의실에 올리는 PPT/PDF/실습 파일 | 학생 개인 파일과 구분 |
| 실시간 수업 | 교수 PC 화면 공유 영상을 수강생이 보는 세션 | 회의/시험감독/녹화 서비스 아님 |
| 익명 글 | 다른 학생에게 작성자 식별자를 노출하지 않는 게시물 | 운영상 완전 추적 불가능이라는 의미 아님 |
| 실명 모집 | 신원 표시가 있는 프로젝트/대회 팀원 모집 | 학교 공식 실명확인 완료라는 의미 아님 |
| 기회 센터 | 장학금·교내근로·공모전·취업 프로그램 목록 | 장학금 지급/합격 확정 시스템 아님 |
| 외부 제출 | 지원자가 기관이 지정한 수단으로 직접 지원서 제출 | 우리 시스템 내 접수 완료 아님 |
| 통합 액션 | 수업·과제·공지·지원 준비 등 할 일을 모아 표현 | AI 추론만으로 학사 사실 생성 금지 |
| P0/P1/P2 | 해커톤 구현 단계 | 플랫폼 전체 필수도 아님 |
| [확정] | 사용자가 명시적으로 동의한 방향 | 구현 스펙 전체 승인 아님 |
| [설계 기본값] | 팀 승인이 없을 때 안전한 작업을 위한 기술 가정 | 사용자의 명시적 결정 아님 |
