DB 연결은 승인된 공통 MariaDB 기반 담당자에게 의존한다. store transaction은 현재 신원/자격·소유권을 매 요청 판정하며 loan/item 및 물리 공간의 시간 범위를 잠가야 한다. 서로 다른 slot ID의 겹치는 시간도 막아야 한다. actor+operation+resource 멱등 namespace와 payload 해시·CAS·활성 대출/예약 유일성·재시도 권한 검증을 같은 원자 트랜잭션에서 보장해야 한다. 프로토콜을 작성한 것으로 실제 DB 보장을 달성했다고 표시하지 않는다.

## 가상 정책과 데이터 경계

실행용 LibraryPolicy 기본값은 없다. 테스트만 `테스트 가상 정책`의 연장7일·최대1회·활성 예약1건·연체 연장 금지·기한 기준 연장을 주입한다. 이는 학교 규정이 아니다. 정책의 기술적 정수 상한 또한 입력 보호 목적의 시연 제약이다. 연장은 기한을 줄일 수 없고, 예약/취소는 서버 aware 시각 기준 시작 전만 허용하는 시연 가정이다. 실제 규정 확정 후 별도 정책/수용 테스트를 승인해야 한다.

모든 레코드 출처는 DEMO이며 실제 개인정보나 학교 원장을 넣지 않는다. 기본 인증·저장소가 없으면503이다. 개인 응답에서 owner_id를 제외하고 다른 사람의 내역을 필터하며 `private, no-store`를 적용한다. 공개 자료 URL의 HTTPS/query 금지는 보수적인 자체 시연 기본값이다. 보호 파일·실제 도서관 API·운영 자격·결제·사서/관리자 승격을 활성화하지 않는다.

FE는 `/library/...`를 공통 requestData에 전달하며 prefix를 중복하지 않는다. 시연 출처/정책/학교 미연동을 표시하고 응답 모양·출처·URL을 확인한다. 네트워크 실패 후 같은 입력의 멱등 키와 양식을 보존하고 성공 후만 비운다. 401/403이면 개인 내역을 제거하며 오류 원인을 남긴다. 공용 검색과 개인 사용 실패를 구분한다.

## 검사와 증거

2026-10-30 base 05086e1에서 실제 실행: API `uv sync --locked`, Ruff·포맷 PASS, pytest 전체 **51 PASS**(신규14, TestClient 비차단 deprecation 경고1), 공개 OpenAPI 스냅샷 일치 PASS. 신규 웹 `npm ci`, 타입 검사, Vitest 전체 **41 PASS**(신규8), 빌드·전체 npm audit0건 PASS. 전역 경로가 미연결이므로 생성 타입·운영 화면·실제 사용자 기록을 추가하지 않는다.
