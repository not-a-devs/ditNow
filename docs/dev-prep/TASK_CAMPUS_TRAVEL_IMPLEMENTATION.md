# TASK-CAMP-TRAVEL — 직접 입력한 강의 간 이동 여유

확인일 2026-10-30. 관련 [FR-CAMP-002와 TC-V1-CAMP-002](../v1-draft/09_FEATURE_TRACEABILITY.csv), [UX](../v1-draft/07_IA_UX.md), NFR-PRIV-001/003, SEC-003, UX-001~005, REL-001. 기존 ID·공식 정책을 변경하지 않는다. 현재 승인된 태스크는 개인 원장 조회가 없는 수동 계산기로 한정한다.

## 구현 계약

- BE `services/api/app/features/campus_travel/`: 명시 offset·초까지 있는 ISO 시각 두 개와 strict 정수 예상 이동 분을 받아 실제 경과 초·이동 초·남는 초 및 겹침/부족/여유0/여유 상태를 계산한다. source는 USER_INPUT, 계산 버전 manual-travel-v1이다. 음수 수업 간격은 오류 대신 겹침으로 표시하며 예상 이동 자체가 음수이면 거부한다. 같은 시각·다음 날짜·UTC/KST도 실제 경과 시간을 사용한다.
- API 제안 `POST /api/v1/campus-travel/calculate`, 공통 SuccessResponse/ErrorResponse, 모든 성공/오류에 private,no-store. `build_travel_router()` 기본 503이며 root가 명시적으로 enabled=True를 주입해야 계산한다. 전역 앱/라우터/OpenAPI를 변경하지 않는다. 이 계산기는 개인 자원을 조회하지 않아 명시 공개 활성화 시 인증 권한을 생성하지 않는다.
- FE `apps/web/src/features/campus-travel/`: 날짜·시각을 KST로 명시 입력하고 서버와 같은 산술·출처·필드 계약을 검증한다. 로딩/빈 입력/오류/503/다시 계산, 수정·unmount 뒤 늦은 응답 폐기를 포함한다. 상태 저장·localStorage·분석 이벤트가 없다. 요청 본문만 전송하고 시각을 URL에 넣지 않는다.
- 기술적 입력 한도: 2000~2099년, 두 시각 차이 절댓값 최대 7일, 예상 이동 0~1440분 정수. 학교 최소 이동 간격·수업 정책이 아니며 악성/비정상 입력을 제한하는 계산기 한도다. 최소 안전 여유값을 발명하지 않으며 0분도 실제 도착 보장으로 표시하지 않는다.

## 조사와 중복 범위

신규 `services/api/app`, `apps/web/src`, `chatbot/app`의 관련 코드를 확인했다. 공개 시설 검색·대학 안내·학사 조회가 있으나 강의 간 이동 여유 계산은 없었다. 사전 `mvp/` 코드를 읽거나 복사하지 않았다. 학교가 이 기능이나 특정 이동 시간을 제공한다는 근거는 UNKNOWN이며 본 구현은 사용자 승인 제품 기능이다. 실제 건물·좌표·경로·접근 동선을 생성하지 않는다.

## DB·권한·차단

DB N_A: 두 입력의 순수 산술 결과이며 보존·조회·수정·삭제 원장, 재고, 거래, 상태 전이가 없다. 멱등 키도 N_A: 동일 입력은 같은 산술 결과를 반환하며 side effect가 없다. 사용자/학적 ID·건물 ID 등 임의 필드는 거부한다. 역할·개인 수강 원장을 조회하거나 부여하지 않는다. 시간표 자동 입력은 승인된 현재 사용자·수강 범위 bridge와 별도 최소 데이터 계약 전 BLOCKED이다. 동작 없는 repository/port를 만들지 않았다.

지도/최단 경로/공식 이동 시간/장애 접근 동선·위치 수집·유료 지도·학교 개인 시간표·실제 이동 검증은 구현하지 않았다. 공식 정책과 연동을 주장하지 않는다. 원격 DB·비밀값·외부 미디어·유료 API는 NOT_RUN. 전역 탐색/라우터/NAV 통합과 독립 리뷰는 root 담당이며 이 PR은 OPEN 유지한다.

## 검증

전용 BE/FE 테스트는 정상/부족/겹침/동일 시각·초 경계/날짜·UTC/KST/잘못된 날짜·offset/정수·한도/추가 필드·출처 주입/기본503·미mount/캐시·입력 로그 비노출/단일 prefix/실제 POST/입력 수정·unmount 뒤 지연 응답을 다룬다. 실제 실행 수·명령·HEAD CI는 PR 본문에 기록한다. 실제 브라우저·배포·공식 이동 소요 시간·개인 원장 격리는 이 무연결 계산기의 시험 결과로 대체하지 않는다.
