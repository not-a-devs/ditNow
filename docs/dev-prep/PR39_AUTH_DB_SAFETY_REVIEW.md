# PR39 학번 로그인·AI 답변 후속 보안 검토

확인일: 2026-10-30. 검토자: 독립 Codex agent. 검토 대상은 PR39 병합 `fe6e7e28d22768a256ee1723ea450d49af2a5efa`이며, 보완은 승인 대기 PR28에 통합한다. AI 검토는 사람의 인증·DB·운영 승인이 아니다. 실제 DB 연결·비밀값 조회·원격 DDL·외부 LLM 호출은 수행하지 않았다.

관련 요구사항: FR-AUTH-001/002, FR-AI-001, RBAC-AI, NFR-SEC-002/004/006, NFR-PRIV-002/003, NFR-AI-001/004, NFR-OPS-004. 학번·초기 비밀번호 로그인과 AI 답변 통합을 승인한 DEC-020은 보존한다. DEC-017의 공통 신원 원장과 DEC-019의 계정 분리·실제 migration 승인도 함께 적용한다.

## 실제 상태

- 공개 검색과 구성된 AI 답변 코드: 기존 구현 보존. 공통 인증·DB 준비의 완료를 뜻하지 않는다.
- 테스트용 학번 인증: 격리 메모리 회귀에 한정. 공식 학교 계정·재학생 인증 아님.
- 원격 신원/개인 학적·공통 권한 bridge: BLOCKED, 기본503.
- 운영 초기화·데이터 병합·스키마 버전/GRANT·TLS 실접속 검증: NOT_RUN.
- 현재 시드 거부는 운영 자료 삭제·복구·승인된 migration을 수행하지 않는다.
- PR28: 인증·DB 보안 경계 변경이므로 CI 성공 여부와 별개로 사람 승인 전 자동 병합 금지.

명령별 검증 결과와 동일 HEAD CI는 PR28 본문에 기록한다. 기존 PR28의 보존된 standalone DB 안전 변경·SecretStr·로그 비식별화와 함께 검증하며, PR39 원본이나 다른 작업을 삭제하지 않는다.
