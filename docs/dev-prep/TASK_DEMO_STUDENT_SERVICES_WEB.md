- 재조회에서 생성/진행 영수증에 해당하는 기록·개정·상태를 확인하거나 취소 기록의 부재를 확인하기 전에는 완료로 표시하지 않는다. 초기 조회 503은 빈 목록이나 쓰기 가능한 상태로 표시하지 않는다.
