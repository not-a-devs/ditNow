## 3. 최종 UI 변경

### 노출 기능

홈, 로그인·계정, 통합 검색, 익명 커뮤니티, 팀원 모집, 장학·기회, 대학·학과 안내, AI 도우미의 **8개 메뉴**를 유지한다.

- 홈 빠른 이동: 익명 커뮤니티 / 팀원 모집 / 장학·기회 / AI 도우미.
- 모바일 하단: 홈 / 익명 커뮤니티 / 팀원 모집 / 장학·기회 / 전체 메뉴. 도우미·로그인·검색·대학 안내는 전체 메뉴로 접근한다.
- README의 첫 세 CRUD 순서와 구현 계약을 보존한다.
- AI 화면은 공개 시설 검색과 규칙 기반 기회·준비 안내를 제공한다. 규칙 기반 결과는 LLM 생성으로 표시하지 않는다.

### 숨긴 요소

- 기본 메뉴·홈·모바일에서 학사·시간표, 내 강의실, 우리 학과, 학생 지원을 숨긴다.
- 숨긴 경로의 직접 접근·끝 슬래시·뒤로 가기 접근은 기능이 mount되기 전에 홈으로 정리한다. 권한 검사를 대신하는 조치가 아니다.
- 홈의 `MY ACTIONS` 준비 중·빈 상태 카드와 `HealthStatus` 서버 연결 확인 카드를 비노출 처리한다.
- Home/Login의 프로세스 메모리 체험을 비노출 처리한다. 원래 모듈·함수·JSX 슬롯은 소스에 보존했다.
- 로그인·시연 데이터 출처·학교 미연동 고지와 실제 기능의 오류·입력 검증·빈 목록 표시는 유지한다.

인증·인가·API·DB·저장·삭제 정책과 Docker·서버 설정은 PR #105에서 변경하지 않았다. 별도로 작성하던 학생 여정·새 홈 카피·MVP 색상 변경은 최종 후보에 포함하지 않았다.

## 5. 앞선 공개 검수의 부분 성공과 미해결 사항

과거 로컬 DB E2E와 최종 배포 E2E를 구분한다. 역사적 근거는 [승인된 기존 E2E 기록](TASK_P0_APPROVED_LIVE_E2E.md)을 참고한다.

- 최종 재배포 전 공개 검사에서 익명 글·모집글의 생성·수정 및 재로그인 후 수정 내용 조회는 성공했다. 첫 실행의 본인 생성 글 2개와 로그인 세션 2개는 기존 API로 정리했다.
- 후속 검수 도구의 잘못된 메뉴 선택자·요청 직렬화·미처리 response-waiter rejection으로 전체 검수가 중단됐다. **도구 실패를 제품 장애나 전체 서비스 FAIL로 단정하지 않는다.**
- 해당 후속 실행은 `finally`가 실행되지 않아 새 테스트 세션의 폐기가 미확인이다. Root의 strict TLS 읽기 전용 확인에서 해당 시간대 테스트 접두 글은 0행, 로그인 시각과 상관된 가상 A 세션은 1행이었다. 시간 상관관계만으로 소유권을 확정할 수 없어 임의 삭제하지 않았다. 미확인 세션 정리를 완료했다고 주장하지 않는다.
- 읽기 전용 DB 연결에서 `SELECT 1`·TLSv1.3·암호화 상태를 확인했다. 체인·호스트명 검증을 유지했고 DB·계정·승인 데이터 수정·삭제·DDL은 수행하지 않았다. CA 지문의 이번 재계산은 미실행이다.
- 공개 화면에서 익명 글 수정·삭제 버튼은 약 **21×16px**, 기회 체크박스는 **13×13px**로 관찰됐다. 기회 필터 라벨 높이도 약 20px여서 24px 기준 미달이다. 기능을 막는 가로 overflow는 없었지만 접근성 검수를 전부 PASS로 표시하지 않는다. Freeze 중 CSS 추가 수정은 하지 않았다.
- 최신 공개 실행의 학생 B 격리·이전 토큰 거부·실제 UI 삭제 전체는 미검증이다. 기존 단위 테스트·이전 E2E 통과를 최신 공개 실행의 성공으로 바꾸지 않는다.
