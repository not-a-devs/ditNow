# 기존 학교 시스템 전수조사 및 문제-기능 근거

## 1. 조사 원칙
- 기존 동의과학대학교 공식 앱·홈페이지·학사 시스템·ASTRA/LMS·출결·도서관·학생지원 서비스의 실제 기능/메뉴/페이지를 조사.
- **사용자 경험**과 **검증된 서비스 화면**을 구분; 사용자의 실제 학번/성적/개인정보 캡처·공유 금지.
- 조사 목적은 기존 시스템 기술을 복사하는 것이 아니라, 새 앱의 기능 baseline을 빠뜨리지 않고 새로 설계하는 것.

## 3. 추가 증거 요청 체크
- 학교 앱 메인/하위 메뉴 전체 스크린샷: 학생정보·공지·학습·도서관·행정 기능 분류
- 장학금 공고 1~2개의 실제 원본 URL/양식·제출방식(개인정보 마스킹)
- 교수/조교/총대 공지 전달 단계의 실제 예시(개인 이름 제거)
- ASTRA/LMS의 강의실 공지·자료·과제·출결 메뉴 실제 현황
- 학교 홈페이지 특정 메뉴에서 다른 웹으로 이동하는 경로
- 학교 교직원 관점의 공지 등록/업무처리 흐름 (가능하면 인터뷰)
