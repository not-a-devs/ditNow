# campus-ux-audit

## Workflow
1. Read `docs/07_IA_UX.md`, applicable FR/NFR, and the actual components under `mvp/src/features/`.
2. Verify core flows: new account navigation; staff notice -> target channel card -> current notice; anonymous vs real-name surfaces; opportunities -> external form; classroom learning before/during/after.
3. Check loading, empty, error, unauthorized, keyboard, focus, contrast, overflow, 390px mobile and 1280px desktop.
4. Distinguish observed behavior from inferred design; capture screenshots/test IDs if executable.
5. Provide prioritized improvements and exact files; do not redesign all UI if not requested.
